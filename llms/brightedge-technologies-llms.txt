# BrightEdge Technologies

> BrightEdge is an enterprise SEO and content performance marketing platform (founded 2007, Foster City, CA). Its AI/ML "Data Cube" powers keyword research, content optimization, competitive analysis, site auditing, SERP and AI-answer tracking, and organic-search measurement for 1,700+ brands. The BrightEdge Platform API (v5.0) is a gated REST API exposing accounts, keywords, competitors, domains, backlinks, page crawl, Core Web Vitals, market insights, AI Catalyst answer metrics, bulk export, and user administration.

## APIs
- [BrightEdge Platform API (Swagger portal)](https://api.brightedge.com/portal): interactive OpenAPI 3.1 reference, 242 paths / 248 operations across 40+ tags.
- [BrightEdge Connect API](https://www.brightedge.com/technology/integration/connect-api): REST protocol connecting content performance, social, web analytics, and marketing KPIs.

## Auth
- HTTP Basic (username/password with API permission) or token headers: X-Token, Bearer-Token, X-BRIGHTEDGE-SESSION. Contact your BrightEdge representative to enable API access. No public OAuth. No public sign-up (enterprise).
